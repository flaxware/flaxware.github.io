IP logging awareness

IPLogger is a link-tracking service, not a privacy or security check. Links created with it can log visitors' IP addresses and related connection details.

Tracking warning
NOTICE: visitor trackingDo not open or share tracking links unexpectedly.

I have not added a direct link to the logger as a privacy tool because it can collect visitor data. Use the DNS and IP diagnostic links above for transparent, consent-based checks.
